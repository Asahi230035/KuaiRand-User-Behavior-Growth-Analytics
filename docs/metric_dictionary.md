# 指标字典

## 1. 通用原则

- 主分析只使用有效标准推荐日志；随机曝光日志单独描述。
- 比例统一按汇总后的分子/分母计算，不平均各小组比例。
- 分母为 0 时结果为空值，不填零伪装成“无转化”。
- 每次曝光/交互是一条日志事件；曝光数不能自动称为播放次数。
- 用户和视频的重复接触保留；不按 `(user_id, video_id)` 去重。

有效事件过滤包含：非空 `user_id`/`video_id`、可解析日期、正毫秒时间戳、`hourmin` 编码合法、`tab` 在 0 至 14、二元字段合法、非负观看/停留时间、来源对应的 `is_rand` 标记。

## 2. 用户活跃

| 指标 | 分子 | 分母/粒度 | 过滤 |
|---|---|---|---|
| DAU | 当日不同 `user_id` 数 | 日期；不除其他数 | 有效标准日志 |
| 日事件数 | `COUNT(*)` | 日期 | 有效标准日志 |
| 事件/DAU | 当日事件数 | 当日 DAU | 有效标准日志 |
| 活跃天数 | 用户至少有一条事件的日期数 | 用户 | 有效标准日志 |
| 首次观测活跃日 | 用户最早有效事件日期 | 用户 | 有效标准日志 |
| 活跃分位组 | 按 `event_count, active_days, user_id` 的 `NTILE(4)` | 用户 | 有效标准日志 |
| 用户占比 | 分层用户数 | 全样本用户数 | 主样本 |
| 事件占比 | 分层事件数 | 全样本事件数 | 主样本 |
| 工作日/周末 DAU | 对应日期 DAU 的算术平均 | 工作日或周末观察日 | 窗口内 |

活跃分位组的主排序键是观察事件量，活跃天数用于打破并列，最后以 `user_id` 保证确定性。结果应理解为观察事件量四分组，而不是绝对活跃等级。

DAU 是固定样本内的“当日出现用户数”，不是平台全量活跃用户。

## 3. 用户参与

共同分母为有效标准日志曝光事件数 `N_exposure`。

| 指标 | 公式 | 解释 |
|---|---|---|
| 长观看率 | `SUM(long_view=1) / N_exposure` | 按曝光计的长观看标记率 |
| 点赞率 | `SUM(is_like=1) / N_exposure` | 按曝光计的点赞标记率 |
| 评论率 | `SUM(is_comment=1) / N_exposure` | 按曝光计的评论标记率 |
| 分享率 | `SUM(is_forward=1) / N_exposure` | 按曝光计的转发标记率 |
| 关注率 | `SUM(is_follow=1) / N_exposure` | 按曝光计的关注作者标记率 |
| 不喜欢率 | `SUM(is_hate=1) / N_exposure` | 按曝光计的负向标记率 |
| 主页进入率 | `SUM(is_profile_enter=1) / N_exposure` | 按曝光计的主页进入标记率 |
| 点击率 | `SUM(is_click=1) / N_exposure` | 只在相同 UI/场景语义内使用 |
| 事件占比 | `tab` 事件数 / 全部有效标准日志事件 | 场景结构 |

`is_click` 在单列界面表示有效播放，在双列界面表示点击。有效播放的发布方阈值为：`duration_ms <= 7000` 时 `play_time_ms >= duration_ms`，否则 `play_time_ms > 7000`。报告只描述其分布，不跨 `tab` 排序点击率。

观看深度：

```text
watch_depth_ratio = play_time_ms / duration_ms
```

只在 `duration_ms > 0` 时定义。保留大于 1 的原值并报告其占比，但该比率不等同于完播率。现有字段无法区分重复播放、循环播放或计量差异。全量分位数使用 DuckDB 近似分位算法。

## 4. 回访与 Cohort

| 指标 | 有效用户 | 分子 | 右截断 |
|---|---|---|---|
| 精确 D1 | `first_seen_date + 1 <= observation_end` | `first_seen_date + 1` 当天再次活跃 | 未来目标日必须已观察 |
| 精确 D3 | `first_seen_date + 3 <= observation_end` | `first_seen_date + 3` 当天再次活跃 | 同上 |
| 精确 D7 | `first_seen_date + 7 <= observation_end` | `first_seen_date + 7` 当天再次活跃 | 同上 |
| 未来 1 至 7 日任意回访 | `first_seen_date + 7 <= observation_end` | 第 1 至 7 日中任一天再次活跃 | 独立敏感性口径 |

`first_seen_date` 是观察窗口内首次出现有效标准日志的日期，不是注册日期。结果名称是“观察到的用户回访率”，衡量窗口内再次出现活动，不估计新增用户留存率。

排除观察起点 Cohort 使用同一公式，把 `first_seen_date = observation_start` 的用户从分母和分子中移除。该口径只描述边界之外的用户，不等同于无左截断的新用户 Cohort。日期口径敏感性显示，改用 UTC+8 时间戳日期会改变“首日”用户集合；因此该结果只作为边界诊断，不作为留存校正。观察截止日附近该 offset 没有合格用户的 Cohort 不进入分母。

## 5. 内容指标

### 5.1 曝光加权

先对每个视频计算：

```text
video_long_view_rate = video_long_view_count / video_event_count
```

某内容组 `g` 的曝光加权比率：

```text
group_long_view_rate_g =
    SUM(video_long_view_count for video in g)
    / SUM(video_event_count for video in g)
```

该口径让高曝光视频按实际曝光权重贡献，回答“用户实际看到的内容事件中标记率如何”。

### 5.2 视频等权

```text
video_weighted_mean_rate_g = MEAN(video_rate for video in g)
```

该口径让每个有曝光视频等权，回答“典型视频的表现如何”。它与曝光加权回答不同问题，不能混用。

### 5.3 时长段与多标签

时长段：`unknown`、`00-15s`、`15-30s`、`30-60s`、`60-120s`、`120s+`。边界按毫秒判定，`unknown` 包含缺失或非正时长。

一个视频的逗号分隔标签会展开到多行；同一视频可同时贡献给多个标签。因此标签结果的事件数之和可能大于总曝光数。只展示达到 `analysis.content.min_tag_exposures` 的标签。

视频统计特征中的 `counts` 是月内日/场景统计记录次数，不是逐事件曝光数。`show_cnt` 等是相应口径的平均统计，不用于与日志事件直接相加。

## 6. 回访关联模型

### 6.1 样本

对每个用户日 `t`：

- 用户在 `t` 有有效标准日志。
- `t + 7` 不晚于观察截止日。
- 特征只来自 `t` 当天。
- 主结局 `returned_d7 = 1` 当且仅当用户在 `t + 7` 当天活跃。

敏感性结局：

- `returned_d1`：`t + 1` 当天活跃。
- `returned_any_7d`：`t + 1` 至 `t + 7` 任一天活跃。

描述性曝光四分位：在完整模型样本内按 `event_count, user_id, activity_date` 使用 `NTILE(4)`。同组人数相等，事件数并列可能使相邻组的最小/最大值相同。各组报告原始 D7 活跃率、显性互动发生比例、平均长观看率和平均点赞率，用于描述强度梯度，不进入因果推断。

### 6.2 变量

主要变量采用适合业务解释和零膨胀数据的口径：

- 日曝光量：`log2(event_count)`，OR 对应日曝光量翻倍。
- 长观看率：乘 10 后进入模型，OR 对应增加 10 个百分点。
- 显性互动发生：`like_count + comment_count + share_count + follow_count` 中任一大于 0 时记为 1。
- 主页进入发生：`profile_enter_count > 0`。

点赞率、评论率、分享率和关注率保留为描述指标，并分别报告“发生/未发生”的 D7 回访率。这些二值行为可以同时发生，同一用户日会进入多个指标，因此各项样本数不能相加。主模型用二值发生指标处理零膨胀比例。控制变量为星期虚拟变量和距观察起点周数。模型中不使用 `is_click` 汇总率，因为单列与双列界面的点击含义不同。

### 6.3 模型

估计器为 Binomial GLM（Logistic 回归）。按日历日期先后切分训练/验证，主报告 OR 来自训练集；标准误按 `user_id` 聚类。四个主变量使用直接业务单位。4 个主变量在同一结局内使用 Holm 法控制多重比较，并同时报告原始与调整 p 值。验证集与训练集共享用户，只检验同一面板内的时间外推。

报告内容：

- 调整 OR 与 95% 聚类稳健置信区间
- 训练/验证日期、样本、结局率
- 验证 ROC AUC、Brier score、log loss
- 训练设计矩阵 VIF
- 精确 D1、未来 1 至 7 日任意回访的替代结局

主 D7 模型的验证 Brier skill score 为负，概率预测不如训练结局率常数基准。系数用于描述样本内条件关联，不估计因果效应，也不用于线上预测。
